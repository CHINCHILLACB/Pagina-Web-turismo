# 🥑 Ruta Gastronómica y Familiar por Floridablanca, Santander 🇨🇴

Una aplicación web interactiva y responsiva diseñada para guiar a turistas y familias locales a través de la rica oferta gastronómica, hotelera y cultural de **Floridablanca** (Santander, Colombia).

## 🚀 Características Principales

* **🏨 Alojamiento Recomendado:** Fichas interactivas con modales informativos de opciones VIP, Moderadas y Económicas, incluyendo integración con WhatsApp, llamada directa y mapas.

* **🍽️ Ruta Gastronómica:** Pestañas organizadas por Desayunos, Almuerzos y Cenas con costos proyectados por persona.

* **⏱️ Itinerario Cronológico Paso a Paso:** Programa sugerido para 2 Días con horario continuo, lugares emblemáticos y costos adaptables por número de viajeros.

* **🧮 Calculador de Presupuesto Interactivo:** Estima el presupuesto global del viaje según el número de personas, días de estadía, nivel de presupuesto (Económico, Moderado, VIP) y paseos adicionales.

* **📱 100% Responsivo:** Optimizado para dispositivos móviles, tablets y computadoras.

## 🛠️ Tecnologías Utilizadas

* **HTML5 & JavaScript Vanilla**

* **Tailwind CSS CDN** (Diseño moderno y fluido)

* **FontAwesome CDN** (Iconografía)

* **Google Fonts** (Inter & Playfair Display)

## 📦 Paso a Paso para Publicar en GitHub Pages

1. **Crear el repositorio en GitHub:**

   * Ve a [GitHub](https://github.com) y crea un nuevo repositorio público (ej. `ruta-floridablanca`).

2. **Subir los archivos:**

   * Sube `index.html` y `README.md` a la rama principal (`main`).

3. **Activar GitHub Pages:**

   * Ve a **Settings** (Configuración) de tu repositorio.

   * En el menú izquierdo, selecciona **Pages**.

   * En la sección **Build and deployment**, bajo **Source**, selecciona `Deploy from a branch`.

   * Selecciona la rama `main` y guarda los cambios.

4. **¡Listo!** En pocos segundos GitHub te dará una URL pública tipo `https://tu-usuario.github.io/ruta-floridablanca/`.
